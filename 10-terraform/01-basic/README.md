# Terraform: базовая практика

Уровень: **базовый**. Выполняется после теоретического интенсива; в его 56 часов не входит.

## Требуется

Terraform и доступ к загрузке provider local; облачный аккаунт не требуется.

## Инициализация

```bash
bash artifacts/init.sh 10 01
cd 10-terraform/01-basic/workspace
```

Команду инициализации запускай из корня курса. Все дальнейшие команды — из рабочего каталога.

## Задание

1. Создай конфигурацию provider local и resource local_file; вынеси текст файла в variable.
2. Выполни init, fmt, validate и plan.
3. Прочитай план и примени создание файла через apply.
4. Измени variable, посмотри plan и примени обновление.
5. Посмотри state без публикации его содержимого; выполни destroy и проверь удаление файла.

## Результат

HCL, результаты plan/apply/destroy и объяснение state. Создание VM не требуется.

Сохрани свои файлы в отдельном учебном Git-репозитории. Приложи наблюдения и объяснения, а не только команды.
