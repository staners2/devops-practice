# Terraform: базовая практика

Уровень: **базовый**. Выполняется после изучения теории по теме.

## Требуется

Terraform и доступ к загрузке provider local; облачный аккаунт не требуется.

## Инициализация

```bash
bash artifacts/init.sh 10 01
cd 10-terraform/01-basic/workspace
```

Команду инициализации запускай из корня курса. Все дальнейшие команды — из рабочего каталога.

## Задание

1. Создай конфигурацию provider local и resource local_file; вынеси текст файла в variable.
2. Выполни init, fmt, validate и plan.

### Чекпоинт: план понятен до применения

- [ ] **Результат:** init и validate прошли, fmt применён; в plan видны ожидаемый local_file и его путь.
- [ ] **Понимание:** Могу объяснить provider, resource, variable и output. Какие изменения я ожидаю от apply?

3. Прочитай план и примени создание файла через apply.

### Чекпоинт: ресурс создан

- [ ] **Результат:** После apply файл существует по ожидаемому пути и содержит значение моей variable.
- [ ] **Понимание:** Могу объяснить разницу plan и apply и проверить реальное состояние файла.

4. Измени variable, посмотри plan и примени обновление.

### Чекпоинт: обновление проверено

- [ ] **Результат:** После изменения variable план показывает ожидаемое действие, apply меняет содержимое файла.
- [ ] **Понимание:** Могу объяснить выбранное Terraform действие по plan, не предполагая заранее, что оно всегда будет update.

5. Посмотри state без публикации его содержимого; выполни destroy и проверь удаление файла.

### Чекпоинт: жизненный цикл завершён

- [ ] **Результат:** State просмотрен локально, не опубликован; после destroy учебный файл отсутствует.
- [ ] **Понимание:** Могу объяснить назначение state и почему он может содержать секреты. Какие ресурсы удалял мой destroy?

## Результат

HCL, результаты plan/apply/destroy и объяснение state. Создание VM не требуется.

Сохрани свои файлы в отдельном учебном Git-репозитории. Приложи наблюдения и объяснения, а не только команды.
