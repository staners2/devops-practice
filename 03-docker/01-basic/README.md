# Docker: базовая практика

Уровень: **базовый**. Выполняется после теоретического интенсива; в его 56 часов не входит.

## Требуется

Docker с Compose; свободный локальный порт.

## Инициализация

```bash
bash artifacts/init.sh 03 01
cd 03-docker/01-basic/workspace
```

Команду инициализации запускай из корня курса. Все дальнейшие команды — из рабочего каталога.

## Задание

1. Создай страницу index.html и Dockerfile на основе nginx, копирующий её в каталог сайта.
2. Собери образ с собственным tag и запусти контейнер с пробросом порта.
3. Проверь страницу через curl, посмотри ps, logs и содержимое контейнера через exec.
4. Останови и удали контейнер; объясни, почему образ остался.
5. Опиши nginx в compose.yaml и подключи страницу через bind mount.
6. Пересоздай контейнер, проверь страницу и объясни отличие bind mount от named volume.

## Результат

Dockerfile, compose.yaml и результаты проверок. Объясни разницу EXPOSE и публикации порта.

Сохрани свои файлы в отдельном учебном Git-репозитории. Приложи наблюдения и объяснения, а не только команды.
