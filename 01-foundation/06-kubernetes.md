# День 6. Kubernetes: управлять запущенным приложением

## Зачем это после Docker

Docker упаковывает и запускает контейнер. Kubernetes управляет приложениями на
узлах кластера: поддерживает желаемое количество экземпляров, размещает их
и организует обновления. Кластер не исправляет ошибки бизнес-логики приложения.

## Основные слова

| Термин | Назначение |
| --- | --- |
| Cluster | Совокупность управляющих компонентов и рабочих узлов |
| Node | Машина, на которой могут работать Pod’ы |
| Pod | Единица запуска одного или нескольких связанных контейнеров |
| Deployment | Поддержание реплик и обновление приложения через ReplicaSet |
| Service | Стабильная точка доступа к выбранным Pod’ам |
| Labels и selector | Метки объектов и способ выбрать нужные объекты |
| ConfigMap и Secret | Несекретная конфигурация и объект для чувствительных данных |
| PVC | Запрос приложения на постоянное хранилище |
| Namespace | Область имён для ресурсов; сама по себе не гарантирует сетевую изоляцию |

## Пример для чтения

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: web
spec:
  replicas: 2
  selector:
    matchLabels:
      app: web
  template:
    metadata:
      labels:
        app: web
    spec:
      containers:
        - name: nginx
          image: nginx:stable
```

Указано желаемое число реплик — две. Selector и labels согласованы. Если
управляемый Pod удалить, контроллер будет стремиться восстановить число реплик.
Фрагмент не создаёт внешний доступ к приложению.

## Что ещё нужно узнавать по названию

Readiness показывает готовность принимать трафик; liveness помогает обнаружить
необходимость перезапуска контейнера. Requests участвуют в размещении и учёте
ресурсов, limits ограничивают потребление. Helm chart описывает шаблоны ресурсов
и параметры, release — установленный экземпляр chart.

Установка кластера, написание chart и самостоятельное применение манифестов
на первой неделе не нужны.

## Самопроверка и ответы

1. Почему после удаления Pod появляется новый?

   **Ответ:** если им управляет Deployment, контроллер восстанавливает желаемое число реплик.

2. Как Service выбирает Pod’ы?

   **Ответ:** обычно через selector по labels.

3. Почему Running не равно Ready?

   **Ответ:** процесс может работать, но ещё не быть готовым обслуживать запросы.

4. Secret — это автоматически зашифрованный текст?

   **Ответ:** нет; кодирование base64 не является шифрованием, нужны корректные права и настройки хранения.
