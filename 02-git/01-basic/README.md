# Git: базовая практика

Уровень: **базовый**. Выполняется после изучения теории по теме.

## Требуется

Git и аккаунт GitHub или GitLab.

## Инициализация

```bash
bash artifacts/init.sh 02 01
cd 02-git/01-basic/workspace
```

Команду инициализации запускай из корня курса. Все дальнейшие команды — из рабочего каталога.

## Задание

1. Создай собственный репозиторий с описанием предыдущего Linux-стенда.
2. Проверь status, добавь файл в staging, посмотри diff и создай commit.
3. Добавь .gitignore для локальных env-файлов; объясни ограничение для уже отслеживаемых файлов.
4. Создай ветку, измени описание и отправь commit на remote.
5. Открой PR/MR, проверь diff и выполни merge.
6. Обнови локальную основную ветку и покажи историю.

## Результат

Ссылка на PR/MR и объяснение clone, commit, push, pull, staging и merge. Разрешение конфликтов не требуется.

Сохрани свои файлы в отдельном учебном Git-репозитории. Приложи наблюдения и объяснения, а не только команды.
