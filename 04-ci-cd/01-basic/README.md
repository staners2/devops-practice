# CI/CD: базовая практика

Уровень: **базовый**. Выполняется после изучения теории по теме.

## Требуется

GitLab-проект, работающий предоставленный runner и registry; результат Docker-практики.

## Инициализация

```bash
bash artifacts/init.sh 04 01
cd 04-ci-cd/01-basic/workspace
```

Команду инициализации запускай из корня курса. Все дальнейшие команды — из рабочего каталога.

## Задание

1. Добавь .gitlab-ci.yml с этапами проверки, сборки и публикации образа.
2. В проверке валидируй конфигурацию Compose; настрой сборку образа доступным способом runner.
3. Публикуй образ в registry с tag по commit SHA; используй переменные авторизации CI.
4. Запусти pipeline по push или MR и прочитай логи каждой job.
5. Внеси ошибку в конфигурацию, зафиксируй падение проверки и исправь её.
6. Объясни, чем публикация образа отличается от deployment и что означает rollback.

## Результат

Pipeline, успешный и неуспешный запуск, опубликованный образ. Настройка собственного runner не требуется.

Сохрани свои файлы в отдельном учебном Git-репозитории. Приложи наблюдения и объяснения, а не только команды.
