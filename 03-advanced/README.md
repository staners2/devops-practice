Этот уровень необязателен и не имеет фиксированного срока. Выбирай задачи,
когда хочется разобраться глубже или появился соответствующий запрос на
собеседованиях. Они не должны задерживать базовый маршрут и начало откликов.
Практика выполняется после теории и соответствующего задания второго уровня.

## Сквозной маршрут

Для связанных задач используй последовательность:

Docker/application → CI/CD/gitlab-delivery → Kubernetes/helm → GitOps →
Observability → PostgreSQL/backup-patroni.

Подготовка приложения — вход в этот дополнительный маршрут, а не утверждение,
что его запуск сам по себе сложнее всех заданий второго уровня. Ansible, Kafka,
Terraform и отдельные сетевые опыты допускают самостоятельную подготовку по
условиям. Внутренние исторические номера модулей в именах ресурсов сохраняются
ради совместимости; актуальное расположение задают ссылки в этом каталоге.

## Инициализация

Из корня курса, пример для Helm:

```bash
bash 02-interviews-and-practice/artifacts/init.sh 03 06 02
cd 03-advanced/06-kubernetes/02-helm/workspace
```

Артефакты общие с уровнем 02, копии создаются только для выбранной практики.
Правила [самооценки чекпоинтов](../02-interviews-and-practice/README.md#как-видеть-прогресс)
сохраняются: нужны наблюдаемый результат и объяснение.

## Требования и готовность

Требования к VM, Docker, Kubernetes, GitLab и облачному аккаунту указаны в
заданиях. Не держи все стенды запущенными одновременно. Облачная практика
платная; после неё проверь удаление оплачиваемых ресурсов.

Для Linux-инцидентов есть условия, но плейбуки подготовки поломок пока
не реализованы. Наличие материалов не подтверждает запуск каждого стенда
на платформе ученика. Отсутствие стенда отмечается как «Не проверено», а не
как выполненный опыт.
