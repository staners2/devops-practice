# PostgreSQL: базовая практика

Уровень: **02 — углубление параллельно собеседованиям**. Выполняй после теории этой темы. Первая неделя не требует этой практики.

## Требуется

Docker и клиент psql (можно внутри контейнера).

## Инициализация

```bash
bash 02-interviews-and-practice/artifacts/init.sh 02 07 01
cd 02-interviews-and-practice/07-postgresql/01-basic/workspace
```

Команду инициализации запускай из корня курса. Все дальнейшие команды — из рабочего каталога.

## Задание

1. Запусти PostgreSQL в отдельном учебном контейнере с named volume и локальным паролем, который не попадёт в Git.
2. Подключись через psql и объясни параметры адреса, порта, базы и пользователя.

### Чекпоинт: соединение с нужной БД

- [ ] **Результат:** psql подключён к учебной базе; я показываю имя базы и пользователя без вывода пароля.
- [ ] **Понимание:** Могу объяснить назначение адреса, порта, базы и пользователя и отличие базы от таблицы.

3. Создай таблицу и выполни INSERT, SELECT с WHERE/LIMIT, UPDATE и DELETE на учебных данных.

### Чекпоинт: изменения данных проверены

- [ ] **Результат:** Для INSERT, SELECT, UPDATE и DELETE есть запросы и фактические результаты на учебных строках.
- [ ] **Понимание:** Могу предсказать, какие строки затронет WHERE. Что произойдёт с UPDATE без условия?

4. Покажи изменение в транзакции и отмену через ROLLBACK.

### Чекпоинт: транзакция отменена

- [ ] **Результат:** После ROLLBACK проверочный SELECT показывает исходное значение, а не отменённое изменение.
- [ ] **Понимание:** Могу объяснить BEGIN, COMMIT и ROLLBACK и выбрать момент подтверждения изменения.

5. Сделай логический backup через pg_dump, восстанови в отдельную базу через pg_restore и сравни данные.

### Чекпоинт: backup восстановлен

- [ ] **Результат:** Dump восстановлен в отдельную новую базу, структура и контрольные записи сравниваются с исходной; исходная база сохранена.
- [ ] **Понимание:** Могу объяснить, почему наличие файла dump не доказывает возможность восстановления.

## Результат

SQL, команды backup/restore и результаты сравнения. Исходную базу при восстановлении не перезаписывай.

Сохрани свои файлы в отдельном учебном Git-репозитории. Приложи наблюдения и объяснения, а не только команды.
