# PostgreSQL: углубление и базовая практика

Уровень 02. Изучай тему параллельно собеседованиям, после обзорной недели.

## Что изучить

- Таблица, строка, столбец, первичный и внешний ключ.
- Подключение psql: адрес, порт, база, пользователь.
- SELECT, INSERT, UPDATE, DELETE, WHERE, LIMIT; транзакции BEGIN/COMMIT/ROLLBACK.
- Назначение индекса и стоимость записи; без настройки сложных планов запросов.
- Логический backup и restore через pg_dump/pg_restore; проверка восстановления в отдельную базу.

## Разбор типового вопроса

Файл backup ещё не доказывает, что приложение удастся восстановить. Нужны восстановление в отдельную базу и проверка данных. Индекс может ускорить выборку, но занимает место и требует обслуживания при изменении записей.
