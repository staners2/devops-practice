# Docker: углубление и базовая практика

Уровень 02. Изучай тему параллельно собеседованиям, после обзорной недели.

## Что изучить

- Образ, контейнер, registry, tag; сборка и запуск.
- Dockerfile: FROM, WORKDIR, COPY, RUN, CMD, EXPOSE; контекст и .dockerignore.
- Публикация портов, адрес прослушивания, переменные окружения, bind mount, named volume и Compose.
- Namespaces, cgroups и устройство изоляции.
- Диагностика runtime: основной процесс, код завершения, OOM, mounts и сеть.
- Multi-stage, слои, BuildKit и кеширование — устройство и чтение примеров.

## Разбор типового вопроса

Контейнер может завершиться сразу после завершения основного процесса. Публикация порта не исправит приложение, которое слушает только loopback внутри контейнера. Обновление tag в registry само по себе не заменяет работающий контейнер.
