# Стартовое приложение

Работай из этого каталога или скопируй его содержимое в собственный учебный проект.

```bash
cp env.example .env
make up
make migrate
make smoke
make ps
```

Требуются Docker с Compose, GNU Make и интернет для загрузки образов.
API доступен на `http://localhost:8080`. `make logs` показывает логи,
`make down` останавливает стенд с сохранением данных.
Для локальных Go-проверок используй версию из `go.mod`.

Для модуля 01 pipeline и настройки GitLab создаются учеником;
`.gitlab-ci.yml` корня курса — существующий пример, не результат твоего задания.
