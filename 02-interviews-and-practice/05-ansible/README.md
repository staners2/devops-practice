# Ansible: углубление и базовая практика

Уровень 02. Изучай тему параллельно собеседованиям, после обзорной недели.

## Что изучить

- Inventory, группы, playbook/play/task/module и минимум YAML.
- Модули apt, file, copy, template, service; переменные и простой шаблон.
- Идемпотентность, become, handlers; проверка конфигурации до reload.
- Syntax check, check mode и чтение changed/failed; назначение и структура roles.
- Collections: что это и для чего используются.
- Работа с секретами: Ansible Vault, хранение пароля Vault отдельно и защита вывода задач.

## Разбор типового вопроса

Повторный запуск исправной конфигурации не должен без причины менять систему. Handler вызывается при изменении связанной задачи. Vault защищает сохранённый секрет, но его всё ещё можно случайно вывести в лог во время применения.
