# Terraform: углубление и базовая практика

Уровень 02. Изучай тему параллельно собеседованиям, после обзорной недели.

## Что изучить

- IaC; provider, resource, variable, output и минимум HCL.
- Init, fmt, validate, plan, apply и destroy.
- State: связь конфигурации с ресурсами, сохранность и чувствительные данные.
- Чтение plan: создание, изменение, удаление и замена; отличие Terraform от Ansible.

## Разбор типового вопроса

Plan показывает предполагаемые действия для текущих входных данных и состояния. Validate проверяет конфигурацию, но не подтверждает права облачного аккаунта. Terraform управляет только выбранными ресурсами и не заменяет резервное копирование данных приложения.
