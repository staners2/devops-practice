# Linux и сети: углубление и базовая практика

Уровень 02. Изучай тему параллельно собеседованиям, после обзорной недели.

## Что изучить

- Shell, PATH, встроенные и внешние команды; абсолютные и относительные пути.
- UID/GID, rwx, chmod, chown, umask; права прохода по каталогам.
- Процессы, PID/PPID, SIGTERM/SIGKILL, zombie/orphan; stdout/stderr, pipes, export и код завершения.
- Systemd: start/stop, enable/disable, status и journalctl. Первичная проверка CPU, памяти, диска и inode.
- IP, маска, подсеть, шлюз, DNS, TCP/UDP, HTTP/TLS. OSI: назначение уровней и связь с реальной проверкой.
- Назначение ip, ss, dig, nc и curl; чтение простого firewall-правила.

## Разбор типового вопроса

Если DNS вернул адрес, это не доказывает доступность порта. Если получен HTTP 500, HTTP-соединение состоялось, а ошибка находится на стороне обслуживающей запрос системы. Проверки проводятся из окружения, где наблюдается сбой.

### Чекпоинт перед практикой

Объясни последовательность DNS → маршрут/порт → HTTP → логи. Что доказывает каждый успешный шаг и чего он ещё не доказывает?
