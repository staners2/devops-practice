# Kubernetes: базовая практика

Уровень: **базовый**. Выполняется после теоретического интенсива; в его 56 часов не входит.

## Требуется

Готовый учебный кластер, kubectl, Helm и предоставленный StorageClass.

## Инициализация

```bash
bash artifacts/init.sh 06 01
cd 06-kubernetes/01-basic/workspace
```

Команду инициализации запускай из корня курса. Все дальнейшие команды — из рабочего каталога.

## Задание

1. Создай namespace и Deployment nginx с двумя репликами; сопоставь Pod, ReplicaSet и Deployment.
2. Создай ClusterIP Service и проверь доступ через port-forward; проверь labels и selector.
3. Подключи ConfigMap и Secret, задай requests/limits и readiness/liveness probes.
4. Обнови image, проверь rollout и выполни rollback.
5. Подключи PVC и проверь сохранность учебного файла после пересоздания Pod.
6. По очереди воспроизведи неверный image tag, ошибочный selector и остановку процесса. Найди причины через get, describe, events и logs.
7. Установи небольшой предоставленный Helm chart, изменив один параметр values.

## Результат

Манифесты, результаты rollout, storage-проверки и объяснение трёх неисправностей. Установка кластера не требуется.

Сохрани свои файлы в отдельном учебном Git-репозитории. Приложи наблюдения и объяснения, а не только команды.
