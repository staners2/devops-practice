# DevOps: три уровня обучения

Курс начинается с недели теории. Затем ты выходишь на собеседования и
параллельно углубляешь знания с базовой практикой. Дополнительные сложные
задачи выполняются по желанию, без обязательного срока.

| Уровень | Срок и цель | Содержание |
| --- | --- | --- |
| [01 — база](01-foundation/README.md) | Неделя: понять назначение технологий и основные слова | Теория, готовые примеры для чтения, вопросы и ответы. Самостоятельной практики нет |
| [02 — углубление и собеседования](02-interviews-and-practice/README.md) | Ориентир 2–3 недели: объяснять детали и выполнять простые действия | Теория по темам и десять базовых упражнений с чекпоинтами |
| [03 — дополнительные задачи](03-advanced/README.md) | Необязательно, без фиксированного срока | Одиннадцать задач: поставка, инфраструктура, GitOps, наблюдаемость и эксплуатация |

## Последовательность тем

Linux/сети → Git → Docker → CI/CD → Ansible → Kubernetes.
Затем PostgreSQL → Redis → Kafka → Terraform.

На первом уровне дополнительные технологии изучаются обзорно. На втором
приоритет остаётся у основного маршрута; дополнительные темы и незавершённую
практику можно продолжать позже. Начало откликов не зависит от завершения
всех десяти упражнений или задач третьего уровня.

## Структура

```text
README.md
01-foundation/                 семь теоретических дней
02-interviews-and-practice/     углубление, темы и 01-basic
  artifacts/                   единый источник файлов стендов и справочников
03-advanced/                   необязательные задания по темам
```

Уровень обучения и номер упражнения различаются. Например,
`02-interviews-and-practice/06-kubernetes/01-basic` — первая практика Kubernetes
на втором уровне. `03-advanced/06-kubernetes/02-helm` — дополнительное задание
третьего уровня. Внутри практик сохранены исходные условия и чекпоинты.

## Как начать

Сначала открой [первый уровень](01-foundation/README.md). Для чтения теории
и вопросов не нужно устанавливать инструменты или готовить стенд.
Все примеры первой недели предназначены для разбора; их выполнение не требуется.

Для практики второго и третьего уровней нужны Bash, Python 3 и инструменты
из условия выбранного задания. Из корня клонированного репозитория:

```bash
bash 02-interviews-and-practice/artifacts/init.sh 02 06 01
cd 02-interviews-and-practice/06-kubernetes/01-basic/workspace
```

Аргументы: **уровень → тема → задание**. Для дополнительной практики Helm:

```bash
bash 02-interviews-and-practice/artifacts/init.sh 03 06 02
cd 03-advanced/06-kubernetes/02-helm/workspace
```

Уровень 01 не имеет команды практической инициализации. Повторная инициализация
существующего workspace останавливается и сохраняет работу ученика. Рабочие
каталоги исключены из Git курса; для сдачи решений создай отдельный учебный
репозиторий внутри своего workspace. Для доступа к материалам не требуется
переключать ветки, теги или открывать worktree.

Артефакты хранятся по одному разу в `02-interviews-and-practice/artifacts`.
Скрипт копирует материалы выбранной практики в её рабочий каталог. Базовые
упражнения, где конфигурацию пишет ученик, получают пустую папку со ссылкой
на условие; Kafka получает подготовленный Compose. Исходная версия сквозного
приложения собирается из общих файлов и отличий в `overrides/00`.

Профили перечислены в [profiles.json](02-interviews-and-practice/artifacts/profiles.json).
При добавлении практики добавь профиль и команду в её README. Изменение общих
артефактов не обновляет уже созданные рабочие копии. Готовые реализации служат
примерами, а не доказательством выполнения задания учеником.

## Самопроверка и требования

На первом уровне проверяется объяснение своими словами. На втором и третьем —
[результат и понимание](02-interviews-and-practice/README.md#как-видеть-прогресс)
после значимых этапов. Чтение команды само по себе не подтверждает навык.

Готовый учебный Kubernetes-кластер и предоставленный CI runner достаточны
для соответствующих базовых упражнений. Базовый Terraform работает с local_file
и не требует облачного аккаунта. Требования полного сложного маршрута нельзя
автоматически переносить на каждое базовое задание.

Для Linux-инцидентов сформулированы условия, но плейбуки подготовки поломок
пока не реализованы. Облачное углубление платное. Стенды требуют проверки
на платформе ученика; отсутствие возможности запуска отмечается как
«Не проверено», а не как завершённая практика.
