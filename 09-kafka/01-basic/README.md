# Kafka: базовая практика

Уровень: **базовый**. Выполняется после теоретического интенсива; в его 56 часов не входит.

## Требуется

Docker Compose; стенд deploy/kafka-lab копируется при инициализации.

## Инициализация

```bash
bash artifacts/init.sh 09 01
cd 09-kafka/01-basic/workspace
```

Команду инициализации запускай из корня курса. Все дальнейшие команды — из рабочего каталога.

## Задание

1. Запусти предоставленный Kafka Compose как отдельный учебный project.
2. Создай topic и отправь несколько сообщений через Kafka CLI в контейнере.
3. Прочитай сообщения одной consumer group и повтори чтение другой группой.
4. Покажи offsets и lag через consumer-groups CLI.
5. Объясни, почему прочтение не удаляет сообщение и что ограничивает retention.

## Результат

Команды producer/consumer, вывод групп и объяснение partition, offset и lag. Не требуется сложный consumer-код.

Сохрани свои файлы в отдельном учебном Git-репозитории. Приложи наблюдения и объяснения, а не только команды.
